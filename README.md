# בוני בניין — אתר החברה

Next.js 15 (App Router) · React 19 · GSAP + ScrollTrigger · Lenis · CSS Modules. עברית RTL מלאה.

## הרצה

```bash
npm install
npm run dev        # http://localhost:3100
npm run build && npm start   # בדיקת פרודקשן
```

## תלויות פתוחות

1. **טופס יצירת קשר** — לא מחובר לשירות. יש להגדיר `CONTACT_WEBHOOK_URL` (CRM / Make / Zapier). בלי זה ה־API מחזיר 503 והטופס מציג הודעה כנה + קישור מייל מוכן ו־*3840. אין הודעת הצלחה מזויפת.
2. **פונט** — Emerald משתמשים ב־Mikmoret (מסחרי). הוחלף ב־Karantina (OFL) לתצוגה ו־Assistant (OFL) לגוף. החלפה: `--font-display` / `--font-body` ב־`globals.css`.
3. **תמונת ההירו** — המקור באתר הוא 1280×720 בלבד. הוגדלה בעדינות (ללא תוכן חדש). מומלץ לבקש מהאדריכל/המדמה קובץ ברזולוציה מלאה.
4. **נתונים לבירור** (מסומנים בקוד):
   - "בית ספר אבטליון – באר יהושע": באתר המקור השדות מוסטים (האדריכל מופיע תחת "מס׳ קומות", היזם "עיריית בני ברק" תחת "אדריכלים"). תוקן לפי ההיגיון; העיר לא הוצגה במפה.
   - "יגאל אלון 43": באתר המקור מופיע טקסט פנימי "נדרש מידע נוסף…" — הוסר. אין תמונה (רק לוגו).
   - "החורש 18": אין תמונות באתר המקור.
   - "מוסך וולוו־הונדה־יגואר", "בית קלימוטק": ללא עיר — לא מוצגים במפה.
   - שעות פעילות: באתר "09:00-17:00" ללא ימים.
   - הנתונים 500+ פרויקטים / 500,000 מ״ר / 25 פרויקטי התחדשות — מהמונים בעמוד הבית; תואמים לטקסט באודות.
5. **המלצות לקוחות** — אין המלצות מאומתות במקור. הרכיב מוכן (`testimonials` ב־`src/data/media.ts`) ומוצג רק כשיתווספו.
6. **הצהרת נגישות / מדיניות פרטיות** — הקישורים מפנים לעמודים הקיימים ב־bonei.co.il.
7. **ANIMTD** — שרת ה־MCP נכשל בהתחברות (מנוי שפג), ולכן התנועה נבנתה ידנית ב־GSAP.

## עיצוב מחדש אחרי ההירו (נובמבר 2026)

הרצה: `npx next dev -p 3200` (או `bonei-new` ב־`.claude/launch.json`). צילומי לפני/אחרי ובדיקות: `_qa/redesign/`.

- **ההירו קפוא**: `HeroSequence`, `Header`, `SmoothScroll`, `motion.ts`, `layout.tsx` זהים בייט לבייט למקור; `globals.css` רק הוארך. נקודת המסירה: `MarketingProjects` נושא `id="intro"` ו־`data-intro-line` כמו הסקשן הקודם.
- **דף הבית**: פרויקטים בשיווק → תחומי פעילות → תו האיכות → אודות → הנהלה → קשר + פוטר.
- **דפים**: `/projects` (ארכיון עם סינון ב־URL), `/urban-renewal`.
- **פונטים**: Karantina (תצוגה), Heebo (טקסט בשכבה החדשה, הותאם להדמיית האודות), Marcellus (כותרות לטיניות). הכותרת באודות מכווצת אופטית (`scaleX .84`) כי Karantina רחב מהפונט שבהדמיה.
- **פערים פתוחים**: טופס לא מחובר (`CONTACT_WEBHOOK_URL`); התמונה בהדמיית האודות הורחבה בשוליים (שמיים/דקל ימני) מעבר לצילום המקורי, והשוליים מושלמים בגוונים מהצילום; באג קיים במקור: אחרי "חזרה" לדף הבית, שכבת העננים של ההירו נתקעת מעל התוכן (`_qa/redesign/14-*`).
